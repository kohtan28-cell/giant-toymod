# Giant Toymod

Roblox 用の Giant Toymod スクリプトです。

## Loadstring

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/kohtan28-cell/giant-toymod/main/loader.lua"))()
```

本体を直接読み込む場合:

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/kohtan28-cell/giant-toymod/main/giant_toymod.lua"))()
```
